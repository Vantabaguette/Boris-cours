# Guardia School Cybersecurity Lab - Technical Scripts Portfolio

This repository aggregates practical Python scripts engineered during the "Cybersécurité et fondamentaux du numérique" professional training program at Guardia School. Developed under the supervision of instructor Boris, these projects translate theoretical network and security concepts into functional code implementations.



## Technical Documentation 

### Repository Structure
The project is built entirely in Python and focuses on network auditing, database vulnerabilities, and foundational software logic.

#### 1. FTP Security Scanner (`FTPScanner.py`)
A network scouting utility built to interface with FTP services. It manages socket connections and parses server response banners to audit availability and identify basic authentication endpoints.
* Focus: Socket programming, protocol interaction, response status validation.

#### 2. SQL Injection Simulation & Theory (`SQL injection.py`)
An educational suite designed to demonstrate web and database vulnerability mechanics. It contains both executable simulations of unvalidated input exploitation and inline lessons mapping defensive secure-coding principles.
* Focus: Security awareness, data sanitization vulnerabilities, SQL syntax manipulation.

#### 3. Local Automation Tool (`To do list.py`)
A programmatic workflow utility managing state operations. It applies data handling and execution loops to control local tasks.
* Focus: Dynamic state management, input parsing, error resistance in terminal loops.



## Documentation Technique 

### Structure du Dépôt
L'ensemble des scripts est développé en Python et traite d'audit réseau, d'analyse de vulnérabilités et de logique de programmation de base.

#### 1. Scanner d'Audit Réseau FTP (`FTPScanner.py`)
Un utilitaire réseau configuré pour interagir avec les services FTP. Le script gère l'ouverture de sockets réseau et analyse les bannières de réponse du serveur afin de vérifier la disponibilité et la sécurité des points d'accès.
* Spécificités : Programmation réseau, sockets, analyse des codes de retour protocolaires.

#### 2. Simulation et Théorie de l'Injection SQL (`SQL injection.py`)
Un module pédagogique illustrant les failles d'injection au sein d'architectures de bases de données. Il intègre un environnement de test interactif combiné à un support de cours intégré détaillant les méthodes de sécurisation et de filtrage des requêtes.
* Spécificités : Sensibilisation offensive, remédiation de code, manipulation de requêtes SQL.

#### 3. Outil d'Automatisation Locale (`To do list.py`)
Une application en ligne de commande structurant la gestion d'un état persistant local. Ce projet met en œuvre des boucles de contrôle pour administrer des flux de données simples.
* Spécificités : Gestion d'état dynamique, traitement des entrées utilisateur, robustesse des boucles d'exécution.
